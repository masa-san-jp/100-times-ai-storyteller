# ADR-0005：ユーザーには出力文字数ではなく物語の規模を指定させる

- 状態：Accepted
- 日付：2026-09-26

## 背景
ユーザーが物語の大きさをどう指定するかを決める必要があった。

## 判断
ユーザーは規模（時間の幅・空間の幅・主要人物・筋・変化の及ぶ範囲）を、プリセットまたは軸ごとに指定する。出来事数と出力の分量は、規模と様式からコードが導く。

## 理由
- 短い物語で長編のスペクタクルは表現できない。物語の分量は、規模から必然的に決まるべきものである。
- 文字数を指定させると、規模に見合わない引き延ばしや圧縮が起きる。

## 影響
- 規模の定義は [scale.md](../spec/scale.md) を原本とする。
- 様式プロファイルは「出来事1件あたりの分量」を持つ（[format-pipeline.md](../spec/format-pipeline.md)）。
