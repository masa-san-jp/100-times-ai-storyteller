# ADR-0001：先行リポジトリを呼び出さず、定義を取り込んで独立させる

- 状態：Accepted
- 日付：2026-09-26

## 背景
先行3リポジトリ（heroes / heros-journey / world-building）を、オーケストレータから呼び出して使うか、必要な定義を取り込んで独立したハーネスにするかを決める必要があった。

## 判断
先行リポジトリは関連リポジトリとして明記するにとどめ、実行時には依存しない。必要な定義と知見を本リポジトリに取り込む。

## 理由
- 先行リポジトリは、コードの中からLLMを直接呼ぶパイプラインである。外部の実行者がタスクを実行するという本リポジトリの前提（P1）と合わない。
- 1回の呼び出しに大きな文脈を渡す設計が多く（100件のリストをまとめて渡す、世界設定の全体を渡す等）、小さいローカルモデルで完走するという原則（P5）に反する。
- 3作の間に重複する工程があり、呼び出すと同じ推論を複数回実行することになる。
- 先行リポジトリの変更に、本リポジトリの動作が左右されないようにする。

## 影響
- 取り込む定義と重複の統合方法は [LINEAGE.md](../LINEAGE.md) を原本とする。
- 先行リポジトリで定義が改良されても、自動では反映されない。反映する場合は LINEAGE.md を更新して取り込む。
