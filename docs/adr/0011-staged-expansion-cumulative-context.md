# ADR-0011：段階的拡張と累積的コンテクストで、プロットから物語を作る

- 状態：Accepted
- 日付：2026-10-18
- ADR-0010 の判断 §1・§3〜§5 を置き換える（ADR-0010 の背景は維持する）。

## 背景
このシリーズの物語生成の思想は、先行シリーズの設計文書に書かれている。
- world-building（`DESIGN_SPEC.md` §2）：
  - 段階的拡張：「各ステージの出力が次のステージの入力となる積み上げ型アーキテクチャ」。ユーザーの入力を、願望・能力・役割の一覧、多層的な世界設定、章ごとの詳細なプロット、本文へと、100倍に広げる。
  - 抽象解釈：「ユーザーコンテクストを直接引用せず、抽象的に解釈・再構築することで創発的な世界を生成」。
  - 累積的コンテクスト：「後段のプロンプトには前段の全生成結果を累積的に投入し、世界観の一貫性を維持」。プロットは、全世界設定・ユーザーの文脈・プロットの型・全人物から作る（§6.5.1）。
- heros-journey（`docs/design-specification.md`）：
  - 「作家の深層心理を物語に昇華する」：入力の全項目から、願望・抑圧・葛藤を分析し、人物と物語に投影する（§1.3、§8）。
  - 「ランダム性による多様性」（§1.3）。
  - プロットは、人物、ランダムに選んだプロットの型、ランダムに選んだ解決すべきテーマから作る（§10.3）。プロットの型は、中核構造・必須の転換点・人物の要件・時間の設計・葛藤の種類・クライマックスの条件・緩急の原則で物語を駆動する（§10.2）。
  - 物語全体の骨子（日常と欠落、使者、挫折、最も危険な場所と敵対者、帰還と代償、得たものと新しい日常）を先に作り、それを統合したプロットから章を書く（§13・§14）。

推論は1回で終わらない。ハーネスが定めた順に推論を重ね、前の出力を次の入力に積み上げて全体像を作る。推論は重なって広がり、また収束する。全体が平凡な出力に収束しないよう、プロットの型、ゴール（結末）からの逆算、ランダムに割り当てた様々な要素を参照させて、緊張を保つ。

このリポジトリは、P1「LLMに全体像を見せない」と、各カードに局所的な断片だけを渡す設計によって、累積的コンテクストに逆行した。推論が積み上がらず、各推論はその場の材料をなぞるだけになった。不足を禁止事項と検査の追加で補ったため、物語にならないまま、仕組みどうしの衝突が増えた（ADR-0010 の背景）。

## 判断
1. **累積的コンテクスト**：各推論には、前の段階までに確定した生成結果を積み上げて渡す。予算に収まらない場合は、コードが決定的に組み立てる要約（台帳）を渡す。パイプラインの手順と、他のタスクへの指示は見せない。
2. **段階的拡張**：新しいグラフでは、次の段階を順に重ねる。
   1. 入力の素材（S1）と要素の一覧（S2）、ランダムな組み合わせ（S3）。従来どおり。
   2. 入力の全体の分析：願望・抑圧・葛藤（新設）。
   3. 世界（S4）と人物（S5）。従来どおり。
   4. 物語の骨子：プロットの型の7項目、テーマ、分析、全人物、世界の台帳を参照し、結末を先に決め、そこから型の必須の転換点を逆算して具体化する（新設）。
   5. 各出来事（S7）：骨子、これまでのすべての出来事、全人物、世界の参照を受けて、1件ずつ作る。
   6. 場面（S7.detail）と様式化（F）：骨子を含む累積的コンテクストを受けて書く。
3. **1回の推論で1つの要素**（ADR-0008）は維持する。累積は、要素の推論に渡す入力で実現する。
4. **参照で導き、禁止で縛らない**：カードは、その要素が骨子の中で担う役割と、参照すべき累積的コンテクストを渡す。新しいグラフでは、骨子の代用として足した筋の条件（S7.condition とその検査）と、出来事・場面のカードの禁止事項の列挙を使わない。整合は累積的コンテクストで保ち、検査は事実の矛盾の確認だけを残す。
5. **予算**：P5（20B前後のローカルモデルで完走）は維持する。20B前後のモデルの文脈長に合わせ、累積的コンテクストを受けるカードの `max_input_chars` を引き上げる。値は仕様で定める。

## 理由
- 先行シリーズの思想そのものであり、このリポジトリはそれを外れたことで物語を生成できなくなった。
- 推論を積み上げ、型・結末・要素を参照させることで、推論が平凡へ収束することに抗える。断片と禁止では、それができない。

## 影響
- VISION P1 を改める。
- story-pipeline：分析の段階、骨子の段階を加え、S7・S7.detail の入力を累積的コンテクストに改める。新しいグラフでは S7.condition と条件の検査を作らない。
- format-pipeline：F2 に骨子を渡す。
- 既存のグラフと run は従来どおり。版を上げ、キャッシュを分ける。
