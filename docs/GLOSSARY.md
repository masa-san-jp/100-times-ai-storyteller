# 用語集

- 所有範囲：用語の定義。文書・コード・タスク定義では、ここに書いた用語を使う。

| 用語 | 英語・コード上の名前 | 定義 |
|---|---|---|
| ハーネス | harness | 実行者に、何をどの順で、どの入力で、どの形式で出力するかを与える仕組みの全体。タスク定義・テーブル・オーケストレータからなる |
| 物語生成ハーネス | story pipeline | 入力から正本を作る工程 S0〜S9 |
| 様式化ハーネス | format pipeline | 正本から様式別の出力を作る工程 F0〜F4 |
| オーケストレータ | orchestrator (`st`) | タスクDAGの管理、タスクカードの生成、検証、保存、コード処理を行う決定的なプログラム。LLMを含まない |
| 実行者 | executor | タスクカードを受け取り、出力を作って提出する外部の主体。コーディングエージェント、ローカルLLM、チャットモデル＋人間 |
| 開発者 | developer | このリポジトリを実装・改修・保守する人またはエージェント。実行者とは別の役割 |
| タスク | task | 実行の最小単位。コードタスク（`code`）とLLMタスク（`llm`）がある |
| タスク定義 | task definition | タスクの入力スロット・手順・出力スキーマ・検証規則を記述したファイル |
| タスクカード | task card | タスク定義に具体的な入力を埋め込んだ、実行者に渡す自己完結したプロンプト |
| 提出 | submit | 実行者がタスクの出力をオーケストレータに渡すこと |
| claim | claim | 実行者がタスクを取得し、他の実行者が取らないようにロックすること |
| lease | lease | claim の有効期限。期限が切れたタスクは、他の実行者が再び claim できる |
| run | run | 物語1本の生成単位。専用のディレクトリと manifest を持つ |
| バッチ | batch | 同じ入力・規模から、複数の run をまとめて作る単位 |
| manifest | manifest | run またはバッチの状態・seed・設定・タスクの状態を記録するファイル |
| 正本 | canonical story | 物語生成ハーネスの最終出力。出来事を5W1H形式で記述した説明的な物語。`story.json` と `story.md` |
| 様式 | format | 正本を整形する出力形式（小説・映画シナリオ・プレゼンテーション等） |
| 様式プロファイル | format profile | 様式の単位・分量・規則・テンプレートを定義したファイル |
| 単位 | unit | 様式化で1回のLLMタスクが扱う範囲（章・シーン・スライド等） |
| ナラティブ | narrative | ユーザーの傾向を13項目で記述した入力。個人情報を含まない |
| 自由入力 | free input | ナラティブの形式によらない、ユーザーが自由に書いた入力 |
| 素材 | material | 入力から抽出・抽象化された要素。S1 の出力 |
| 要素プール | element pool | 願望・能力・役割などの軸ごとに蓄積された要素の集合。S2 で拡張される |
| 要素テーブル | element table | 要素プールの既定値・増補値を保持するファイル |
| 規模の軸 | scale axis | 規模を構成する次元（時間の幅・空間の幅・主要人物・筋・変化の及ぶ範囲） |
| 規模 | scale | 物語が扱う時間・空間・人物・筋・変化の範囲。出力文字数ではない |
| 規模プリセット | scale preset | 規模の軸の値の組。掌編・短編・中編・長編・大河 |
| プロット型 | plot type | 物語の型（旅、復讐、再生など）。固定テーブルからコードが選ぶ |
| 構造テンプレート | structure template | 段階の並び（3拍、起承転結、12段階など） |
| スロット | slot | 構造テンプレートを展開して得られる、出来事1件分の枠 |
| 出来事 | event | 正本を構成する1件の記述。when / where / who / why / what / result を持つ |
| 役 | role | 人物の物語上の機能。protagonist（主人公）・messenger（使者）・supporter（支援者）・adversary（敵対者）・bystander（傍観者） |
| sources | sources | LLMタスクの出力が使った素材のIDの一覧 |
| 指紋 | fingerprint | 重複検出のための、正規化した内容のハッシュ |
| 部 | part | 大河規模で、物語を分ける大きな区切り。部ごとに主筋と構造テンプレートを持つ |
| 入力由来の比率 | input ratio (`r`) | S3 で、要素を入力由来プールから選ぶ確率。run ごとに seed で決める |
| 名前の響き | name sound set | 名前の音の集合と、その響きの説明文。S5 で名前を組み立てる材料 |
| 原則層・仕様層 | principle layer / spec layer | 原本の変更権限の区分。原則層は所有者の決定が必要、仕様層は開発者が変更できる |
| ticket | ticket | claim ごとに発行する不透明な文字列。タスクカードの見出しに書き、実行者は ticket で提出する。タスクIDは実行者に見せない |
| 無効化 | invalidate | 後続の検査が不合格とした `done` のタスクを、試行回数を増やして `ready` に戻すこと |
| 不在の役 | absent role | 構造テンプレートが要求するが、人物の数が足りず割り当てられなかった役 |
| 要素の軸 | element axis | 要素の種類（want, ability, duty, taboo, place, era, object）。規模の軸とは別 |
