# ナラティブ記入ガイド

- 所有範囲：ナラティブの記入例（良い例・書きすぎの例）。項目・問い・字数・個人情報の検出規則は [spec/input.md](../spec/input.md) が原本であり、ここには複写しない。

## 1. 書き方の原則

- 書くのは、**あなたがどのような傾向を持っているか**だけです（[spec/input.md](../spec/input.md) §2.1）。感じ方・惹かれ方・恐れ方・抑え方を、一般的な言葉で書きます。
- 具体的な出来事・人物・場所・日付は書きません。固有名詞（人名・組織名・作品名など）も書きません。人名と組織名は機械では検出できないため、書かないことはあなたの側で守ってください。
- 項目ごとの問いと「書かないこと」は、[spec/input.md](../spec/input.md) §2.2 の表にあります。字数の上限もそこにあります。
- 13項目のうち、空でない項目が少なくとも3つ必要です。書けない項目は空欄のままにしてください。サンプル値で補う必要はありません。
- メールアドレス・電話番号・郵便番号・URL・SNSハンドル・住所・長い数字・具体的な年月日は、取り込み時に検出され、拒否されます（[spec/input.md](../spec/input.md) §4）。検出された場合は、表現を変えてください（例：「3024年」を「遠い未来」にする）。
- 書いた内容は、`st check-input` で取り込む前に確かめられます（[spec/cli.md](../spec/cli.md)）。

## 2. 項目ごとの記入例

各項目に、**良い例**（傾向だけを書いたもの）と**書きすぎの例**（具体の出来事や固有名が入ってしまったもの）を示します。書きすぎの例は、悪い見本として示すもので、そのまま使ってはいけません。見出しの文字列がナラティブ JSON のキーです。

### `author`（人となり）

- 良い例：慎重で、物事を決める前に何度も確かめる。人の話を最後まで聞くのは得意だが、自分の考えを先に出すのは苦手。
- 書きすぎの例：東京の出版社に勤める三十二歳の編集者で、世田谷区に一人で住んでいる。

### `missing`（欠落）

- 良い例：自分の判断を信じ切る感覚が欠けていると感じる。それは、誰にも頼らず立てる強さの象徴だと思う。
- 書きすぎの例：父が会社を畳んだせいで、私には安定という感覚がない。

### `status`（現在地）

- 良い例：まだ満たされていない。ただ、欠けていること自体は以前より落ち着いて眺められるようになった。
- 書きすぎの例：二〇二〇年の春に転職してからは、少しずつ満たされてきた。

### `memories`（形成）

- 良い例：周囲の期待に応え続けた経験と、一人で黙々と何かを作り上げた経験が、今の慎重さと粘り強さをつくった。
- 書きすぎの例：小学生のとき、横浜の祖母の家で、いとこの健太と夏の間ずっと過ごした経験。

### `mission`（使命）

- 良い例：誰かの役に立つ前に、まず自分の足で立てるようにならなければならないと感じている。
- 書きすぎの例：来月までに、あの人に謝って、会社を辞めなければならない。

### `success`（成功像）

- 良い例：誰の評価も気にせず、静かに自分の仕事に没頭できて、夜は穏やかに眠れる状態。
- 書きすぎの例：年収を倍にして、鎌倉に家を建て、毎朝海沿いを散歩できる状態。

### `loss`（代償）

- 良い例：築いてきた安定した立場は手放してもいい。ただ、静かに過ごせる時間を失うのは怖い。
- 書きすぎの例：今の会社の肩書きと、友人の美咲との付き合いなら失ってもいい。

### `taboo`（禁忌）

- 良い例：自分を守るために、立場の弱い相手を踏み台にすることだけはしたくない。
- 書きすぎの例：上司の田中部長のように、部下の手柄を横取りすることだけはしたくない。

### `inhibit`（抑制）

- 良い例：失敗して笑われることへの恐れと、期待を裏切ってはいけないという責任感が、自分を抑えている。
- 書きすぎの例：二〇一九年の発表会で笑われた記憶が、人前で話そうとするたびによみがえる。

### `daily`（日常）

- 良い例：朝は静かで、昼は小さな用事に追われ、夜に少しだけ一人の時間が残る。大きな波はないが、何かを置き去りにしている感覚がある。
- 書きすぎの例：毎朝七時に最寄りの駅から急行に乗り、渋谷のオフィスまで通っている。

### `change`（変化の契機）

- 良い例：信頼している誰かに、弱いところを見せても大丈夫だと思えたとき、自分は変わると思う。
- 書きすぎの例：今の恋人の遥が転勤で遠くに行ってしまったら、きっと変わると思う。

### `acceptance`（受容）

- 良い例：不器用でも誠実な人は受け入れられる。取り繕うために平気で嘘をつく態度は、受け入れにくい。
- 書きすぎの例：母の再婚相手のやり方は受け入れられないが、姉の言うことなら受け入れられる。

### `desire`（秘めた願望）

- 良い例：すべての役割を降りて、誰にも説明せずに、しばらく遠くへ行ってしまいたい。
- 書きすぎの例：詳しくは https://example.invalid/mine に書いたが、いつか北海道の小樽に移り住みたい。

## 3. 書いたあとの確認

- 固有名詞（人・組織・作品・地名）が入っていないか。
- 「いつ・どこで・誰と」を、「ある種の経験」「ある種の場所」「ある種の相手」に言い換えられないか。
- 空でない項目が3つ以上あるか。
